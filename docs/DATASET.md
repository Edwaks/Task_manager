# Паспорт продукта

| Поле | Значение |
|------|----------|
| Название | TaskCapitan |
| Репозиторий | Task_manager |
| Категория | среда управления задачами и цифровыми сотрудниками |
| Публичный адрес | https://taskcapitan.ru/ |
| Аудитория | команды, руководители и владельцы повторяемых процессов |
| Ценность | объединяет постановку задач, коммуникацию и помощь искусственного интеллекта |
| Основные сущности | задачи, диалоги, поручения, платформы, цифровые сотрудники и результаты |
| Ключевые роли | Руководитель, Исполнитель и Оператор цифровых сотрудников |
| Язык документации | русский |
| Тип описания | публичное пользовательское |

## Ключевые термины

`задачи и статусы`, `коммуникатор`, `ИИ-секретарь`, `BotCap`, `ИИ-сотрудники`, `подключаемые платформы`, `единая история работы`, `Руководитель`, `Исполнитель`, `Оператор цифровых сотрудников`

## Заметки для индексации

Паспорт предназначен для каталогизации и поиска. Он не является технической спецификацией, договором или перечнем внутренних компонентов.
